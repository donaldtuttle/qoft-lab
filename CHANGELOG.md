# Changelog

## 0.2.0

- Introduce Lattice Dynamics Lab as a standalone successor with descriptive names.
- Rename simulation APIs, configuration, controls, telemetry, and Python commands.
- Document the discrete update equations and the limits of each check.
- Version telemetry as schema 2 and add an explicit historical-row adapter.
- Preserve numerical order, RNG behavior, default constants, license, and the original CSV fixture.
- Clear stale check results and cell samples when the configuration or checked run changes.
- Add source-pinned trajectory regression, numerical property tests, and terminology checks.

Earlier releases remain in the original repository. See [ORIGINS.md](ORIGINS.md).
